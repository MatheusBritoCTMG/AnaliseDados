# 🐍 Atividades de Python — COTEMIG

Repositório com as atividades e exercícios de Python desenvolvidos durante o curso no **COTEMIG**.

Aqui registro minha evolução na linguagem, desde os fundamentos até projetos mais completos, como APIs REST com Flask e banco de dados.

## 📚 Conteúdos abordados

- Fundamentos de Python (variáveis, condicionais, laços, funções)
- Estruturas de dados (listas, tuplas, dicionários, conjuntos)
- Programação Orientada a Objetos
- Manipulação de arquivos
- APIs REST com Flask
- Banco de dados com Flask-SQLAlchemy
- Arquitetura em camadas (MVC)
